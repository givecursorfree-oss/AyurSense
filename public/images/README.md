# Self-hosted images

|------|----------|
| `clinical-insight-herbs.png` | How it works step 02, herbs capability, journey dosha balance |

| `capability-herbs.webp` | Herb recommendation slide |
| `capability-severity.webp` | Severity slide |
| `capability-safety.webp` | Drug safety slide |
| `capability-dosage.webp` | Dosage slide |
| `journey-dinacharya.webp` | Journey article cards |

Target width ~1200px, quality ~80, under 150KB each.
